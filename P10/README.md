# P10 - Advanced Flexbox Header and Footer

**Name:** Ayush Kumar

## Aim
To arrange the header, navigation and footer using Flexbox.

## Tools Used
HTML, CSS, VS Code and a browser.

## What I Made
The `.header-container` and `.footer-container` classes use `display: flex`, `justify-content: space-between`, `align-items: center` and `flex-wrap: wrap`. Navigation and footer links are also arranged with Flexbox. A media query changes the layout for small screens.

## How to Run
Open `index.html` in a browser and resize the window.

## Result
A portfolio header and footer arranged with Flexbox for desktop and mobile widths.
