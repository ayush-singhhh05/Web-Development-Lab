# P08 - Sticky Navbar and Card Overlay

**Name:** Ayush Kumar

## Aim
To learn CSS positioning through a sticky navigation bar and positioned badges.

## Tools Used
HTML, CSS, VS Code and a browser.

## What I Made
The navigation bar uses `position: sticky` and `top: 0`. Each project card uses `position: relative`, while its badge is placed in the top-right corner with `position: absolute`.

## How to Run
Open `index.html` in a browser and scroll the page to observe the navigation bar.

## Result
A portfolio layout demonstrating sticky and absolute CSS positioning.
