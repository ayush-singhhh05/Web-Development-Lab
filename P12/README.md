# P12 - Advanced Portfolio Projects Grid

**Name:** Ayush Kumar

## Aim
To arrange project cards using CSS Grid and make one project stand out.

## Tools Used
HTML, CSS, VS Code and a browser.

## What I Made
The `.project-grid` class creates a three-column grid on larger screens. The featured portfolio card uses `grid-column: span 2` and `grid-row: span 2`. Media queries adjust the columns and featured card on tablets and mobile screens.

## How to Run
Open `index.html` in a browser. Resize the page to see the responsive grid.

## Result
A responsive project gallery that demonstrates column spanning and row spanning.
