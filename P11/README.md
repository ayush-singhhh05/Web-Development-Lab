# P11 - Three-Column Newspaper Layout Using CSS Grid

**Name:** Ayush Kumar

## Aim
To create a newspaper-style page using CSS Grid.

## Tools Used
HTML, CSS, VS Code and a browser.

## What I Made
The page has three topics: Technology, Education and Sports. The `.news-container` uses `display: grid` and three equal columns. Media queries change the layout to two columns on tablets and one column on mobile screens.

## How to Run
Open `index.html` in a browser and resize the window to see the grid change.

## Result
A responsive newspaper-style layout made using CSS Grid.
