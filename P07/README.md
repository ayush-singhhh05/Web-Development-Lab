# P07 - CSS Design Tokens and Typography

**Name:** Ayush Kumar

## Aim
To use CSS variables for colours and fonts and keep a consistent style across a page.

## Tools Used
HTML, CSS, VS Code and a browser.

## What I Made
The page has About Me and Skills sections. In `style.css`, the `:root` selector defines reusable values such as `--primary-color`, `--background-color` and font variables. Headings and body text have separate font settings.

## How to Run
Open `index.html` in a browser. Keep `style.css` in the same folder.

## Result
A styled portfolio page using design tokens and a basic typography system.
