# P06 - Full Portfolio Structure in Semantic HTML

**Name:** Ayush Kumar

## Aim
To build a complete portfolio page structure using semantic HTML.

## Tools Used
VS Code, HTML and a browser.

## What I Made
My `index.html` includes About, Education, Skills, Projects and Contact sections. It also uses a header, navigation links, articles and a footer.

## How to Run
Open `index.html` in a browser. Click the navigation links to jump to different sections.

## Result
A personal portfolio page with a clear HTML structure. This practical focuses on HTML, so advanced styling is not required.
