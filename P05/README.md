# P05 - Semantic Bio Page

**Name:** Ayush Kumar

## Aim
To create a simple personal bio page using semantic HTML.

## Tools Used
VS Code, HTML and a web browser.

## What I Made
The page in `index.html` has a header, an About Me section, an Interests section and a footer. I used `<header>`, `<main>`, `<section>` and `<footer>` to give the page a clear structure.

## How to Run
Open `index.html` in a browser.

## Result
A basic bio webpage with readable semantic HTML sections.
