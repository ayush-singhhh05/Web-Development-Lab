# P13 - Choosing Between Flexbox and Grid

**Name:** Ayush Kumar

## Aim
To choose the right CSS layout method for different parts of the same webpage.

## Tools Used
HTML, CSS, VS Code and a browser.

## What I Made
The page uses Flexbox for the header and navigation, where items need to be arranged in a row. It uses CSS Grid for the project cards, where items need rows and columns. A media query makes the project cards stack on small screens.

## When to Use Which
- **Flexbox:** Best for arranging items along one direction, such as a menu.
- **Grid:** Best for arranging items in rows and columns, such as a card gallery.

## How to Run
Open `index.html` in a browser and resize the window.

## Result
A single portfolio page that uses both Flexbox and Grid appropriately.
