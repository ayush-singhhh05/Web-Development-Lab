# P01 - Project Folder and Terminal Navigation

**Name:** Ayush Kumar  
**Subject:** Programming for Web Development - I Laboratory

## Aim
To learn how to move between folders and create files using the terminal.

## Tools Used
VS Code terminal (or macOS Terminal).

## Commands Practised
```bash
pwd
ls
mkdir P01
cd P01
touch practice.txt
ls
```
`pwd` shows the current folder, `ls` lists its contents, `mkdir` creates a folder, `cd` changes folders, and `touch` creates a file.
