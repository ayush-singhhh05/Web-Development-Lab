
# Practical 4: GitHub README and Version Tags

Name: Ayush Kumar
Subject: Programming for Web Development - I

## Aim
To create a project README file and manage versions using Git tags.

## Commands Used

git add README.md
git commit -m "Add project README"
git push origin main
git tag v1.0
git push origin v1.0

## Result
Successfully created a README file and uploaded the v1.0 version tag to GitHub.
