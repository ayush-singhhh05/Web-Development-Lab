# P04 - GitHub README and Version Tags

**Name:** Ayush Kumar  
**Subject:** Programming for Web Development - I Laboratory

## Aim
To describe a GitHub project using a README and mark a version using a Git tag.

## Tools Used
Git, GitHub, Terminal and Markdown.

## What I Made
- A main `README.md` describing the project and its practicals.
- A version tag called `v1.0`.

## Commands to Understand
```bash
git add README.md
git commit -m "Add project README"
git push origin main
git tag v1.0
git push origin v1.0
```

## Explanation
A README tells visitors what the repository contains. A Git tag gives a particular commit a version name such as `v1.0`.

## Result
Project documentation and version-tag concepts were practised in GitHub.
