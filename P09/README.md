# P09 - Responsive Navbar and Cards Using Flexbox

**Name:** Ayush Kumar

## Aim
To build a flexible navigation bar and project card layout using CSS Flexbox.

## Tools Used
HTML, CSS, VS Code and a browser.

## What I Made
In `style.css`, the navigation links use `display: flex`, `justify-content` and `gap`. The project cards use a flexible container with `flex-wrap: wrap`. A media query at 600px changes the layout to a vertical arrangement for smaller screens.

## How to Run
Open `index.html` in a browser. Resize the browser window to compare the layouts.

## Result
A responsive navigation bar and card layout using Flexbox.
